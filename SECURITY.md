# Security Policy

## Supported versions

Only the latest minor release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately
through [GitHub Security Advisories](https://github.com/aenzenith/laravel-dev-mesh/security/advisories/new).

You will get a response within a few days. Once a fix is ready it is released
as a patch version and the advisory is published.
