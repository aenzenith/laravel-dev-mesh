# Claude Code notes

## Commit messages

Commit messages in this repository are written in **English**, following
[CONTRIBUTING.md](CONTRIBUTING.md): Conventional Commits prefix, imperative
mood, subject under 72 characters.

```
fix(parser): shorten scheduler command summary lines
docs: add Packagist badges to README
```

This overrides any user-level or global rule that asks for commit messages in
another language or tense (such as Turkish past tense). It applies to
subagents too.
